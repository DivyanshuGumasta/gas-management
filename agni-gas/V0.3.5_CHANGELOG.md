# Agni Gas V0.3.5

## Supplier-specific cylinder management

- The supplier profile's Items supplied tab now lists only cylinder sizes linked to that supplier.
- Users can link an active cylinder type from Stock & Price, edit the supplier-specific purchase rate, or unlink that cylinder from the supplier.
- Unlinking affects future purchase options only. It does not change cylinder stock or rewrite purchase history.
- The purchase-options API requires a selected supplier and returns only linked cylinder sizes. The purchase-create API revalidates the supplier link before committing stock and ledger updates.

## Supplier's original invoice

- Purchase registration no longer implies that Agni Gas creates a supplier invoice. The purchase detail screen is an internal ledger/stock entry only.
- Removed the Agni-branded printable purchase record and its WhatsApp share action.
- A purchase can be saved before the supplier's invoice arrives. The original invoice can then be attached from the purchase detail page.
- The detail page previews uploaded invoice images inline and PDFs in an embedded viewer, with an open-original link.
- The user can replace or remove an attachment without changing the purchase lines, stock or supplier balance.
- Uploads remain in the purchase database row as a BLOB and are included in normal database backups.

## Tests

- Added supplier cylinder link, rate update, unlink, available-size and supplier-only purchase-option coverage.
- Added server-side rejection tests for purchases containing unlinked cylinders.
- Added delayed attachment, replacement and removal tests for supplier invoice files.

No database schema migration is required for V0.3.5.
