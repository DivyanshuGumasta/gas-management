# Agni Gas V0.3.4 — Figma-aligned supplier and purchase workflow

This patch aligns the Suppliers & Purchases workspace with the supplied 28-page Figma PDF and the requested APPLY_THESE_EDITS5 corrections.

## Main list pages

- Uses the existing Customers page primitives for tabs, filters, search, cards and list rows.
- Supplier list has search, the shared Export dropdown and Add supplier. The extra supplier summary cards and CSV export are removed.
- Purchases list follows Figma page 18: Today / Last 7 days / This month / All / Custom filters; the Purchases and Payable summary cards; Export dropdown; New purchase; purchase rows with supplier, bill/date/items and paid/due status.

## Supplier profile

- Keeps Ledger, Purchases and Items supplied tabs, profile balance, Purchase, Pay and Statement actions.
- Cylinder checklist remains the way to link cylinder types and enter a supplier-specific cylinder purchase rate.
- Ordinary catalogue items can only be linked from the existing Stock & Price catalogue. New master items are not created here.
- Editing a linked catalogue item on a supplier page changes only that supplier's purchase rate.

## New purchase

- Uses the same supplier picker modal as the rest of the application, in a supplier picker card.
- Shows only cylinder sizes and ordinary catalogue items linked to the selected supplier.
- Cylinder cards have Rate, Full in and Empty out steppers, the Bought new empty cylinders expander and an amount footer.
- The payment panel includes date, Paid / Partially paid / Credit, payment source, amount paid, GST rate/amount, price-update toggle, supplier bill attachment and note.
- The extra Add supplier and Create item controls have been removed from this form. Link suppliers/items from their dedicated pages; create master items in Stock & Price.

## Backend and validation

- `GET /api/purchases/options` returns an empty list without a supplier and returns only linked cylinder types when a supplier is selected.
- `POST /api/purchases` validates cylinder-to-supplier links both before and inside the write transaction. Existing ordinary catalogue-item link checks remain in place.
- Supplier catalogue-item creation now requires an existing `item_id`; supplier editing changes only `supplier_catalog_items.purchase_price_paise`.
- No database table changes are required by this patch; it uses the supplier/purchase/catalogue tables already introduced in V0.3.2/V0.3.3.

## Known boundaries

- Stock & Price master-item creation/edit UI is still a separate module to implement.
- Export dropdowns use the shared export placeholder until the Reports/export work is implemented.
- Purchase cancellation/reversal remains out of scope in this patch.
- Purchase detail is an internal record and can open the supplier's original attachment; it does not generate a replacement supplier invoice.
